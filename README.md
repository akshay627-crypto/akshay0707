# Akshay the Coder

A responsive, dependency-free portfolio for Akshay Kumar. It keeps the Ben 10 / Omnitrix-inspired dark-green identity and presents scoped freelance services, project records, technical interests, and direct contact links.

## Run locally

Open `index.html` directly, or serve this folder over HTTP:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`. There is no package installation or build step for the portfolio.

## Projects and evidence

- PALM-WGB links to its public site. The site’s own sample projects and testimonials are demo content; this portfolio does not claim an individual code contribution breakdown or an unpublished stack.
- College Network, LINK-HP, and PharmaGuard AI are described from existing portfolio/project notes. Their original source repositories or live demos are not linked here, and implementation details are limited to what those notes document.
- RAIL-CAUTION AI is linked to the included `demos/rail-caution-ai.html` browser prototype. Its README and interface label all values as synthetic and the interactions as a deterministic demo, with no live railway connections, trained model, or operational instructions.
- Telegram and cloud automation is presented as personal experimentation, not as a production service. No credentials, session files, or private Telegram content are included.

The project visuals drawn in HTML/SVG/CSS are illustrations, not screenshots of project interfaces. The hero, About, and Tech Arsenal sections use four of the supplied Ben 10 artworks; the other supplied files remain in `assets/`.
